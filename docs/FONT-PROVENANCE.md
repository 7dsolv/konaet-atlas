# Fonte Manrope

O arquivo `assets/studio/manrope-latin.woff2` contém a fonte variável Manrope,
normal, pesos 400–800, no subconjunto Latin fornecido pelo Google Fonts.
Foi copiado sem alterações do pacote local KONAET Music em 13/11/2026.

- Autoria e fonte: https://github.com/google/fonts/tree/main/ofl/manrope
- Binário de origem: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- Tamanho: 24.532 bytes
- SHA-256: `8c2def024c1bf31aacf3624ae3c4d701269b4ec3dc765c04830839f0d36b2d9e`
- Licença: SIL Open Font License 1.1, incluída em `assets/studio/FONT-LICENSE.txt`

O navegador carrega a fonte do próprio GitHub Pages. O projeto não reivindica
a autoria da fonte. Caracteres fora do subconjunto usam a fonte de sistema.
